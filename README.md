# ThinkRush Logical Games

A polished static brain-game platform built with HTML, CSS and JavaScript.

## Included
- 11 playable games
- Responsive dark-first UI
- Search + category filters on the home page
- No mandatory account or payment flow
- Local browser storage where used by individual games
- SEO-ready metadata, robots.txt, sitemap.xml, manifest and 404 page

## Run locally
Open `index.html` in a browser, or run a simple static server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000/`.

## Deploy
Upload the folder to GitHub Pages, Vercel, Netlify or Cloudflare Pages. After deployment, replace `https://YOUR-SITE-URL/` in the canonical/OG/structured-data fields and update `sitemap.xml` with the real domain. Then submit the sitemap in Google Search Console.
